TaskBoard release {{ .Release.Name }} rendered into namespace {{ .Release.Namespace }}.

Create the database secret before the pods can start. The chart does not contain a password.

  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.postgres.existingSecret }} \
    --from-literal=username=taskboard \
    --from-literal=password='REPLACE_WITH_A_LONG_RANDOM_PASSWORD' \
    --from-literal=database=taskboard

The API builds DATABASE_URL from that secret and the Service {{ include "taskboard.fullname" . }}-postgres.
